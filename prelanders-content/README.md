# Prelanders - Marketing Landing Pages

This directory contains marketing landing pages for the Hamlatzli recommendation platform.

## Files Included

### 1. main-landing.html
The main marketing landing page that introduces the entire platform with all categories and features.

### 2. landing-restaurants.html
A focused landing page for restaurant recommendations, highlighting:
- Authentic reviews from real visitors
- Location-based restaurant discovery
- Exclusive tips and recommendations

### 3. landing-movies.html
A dedicated landing page for movie recommendations, featuring:
- Different movie categories (drama, comedy, action, thriller)
- User reviews and ratings
- Genre-based recommendations

### 4. landing-books.html
A specialized landing page for book recommendations, including:
- Various book categories (literature, science, business, self-development)
- Reading community statistics
- Personalized book discovery

## Usage

These landing pages can be used for:
- Marketing campaigns
- Social media promotion
- Category-specific advertising
- SEO optimization for different keywords

## Integration

To integrate these pages with the main application:

1. Copy the files to the `public/` directory
2. Update navigation links as needed
3. Ensure CSS styles are compatible with the main application
4. Add tracking/analytics code if required

## Styling

All pages use:
- RTL (right-to-left) layout for Hebrew text
- Responsive design for mobile compatibility
- Modern CSS with gradients and backdrop filters
- Consistent color scheme across all pages

## Links

All pages include call-to-action buttons that link to:
- `/index.html` - Main application
- `/register.html` - User registration
