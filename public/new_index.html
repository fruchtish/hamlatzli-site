3

שתפו את ההמלצות שלכם

שתפו את הרשימה המושלמת שלכם עם חברים, עוקבים או לקוחות. אפשר להוסיף את הקישור לביו, לינקטרי או לשלוח ישירות.

למה להשתמש בהמלצלי?

פלטפורמה מושלמת לשיתוף ההמלצות שלכם - פשוט, יפה ועם יתרונות רבים

עיצוב מרהיב

רשימות ההמלצות שלכם יוצגו בצורה מושכת ונגישה, עם תמונות, דירוגים ופרטים חשובים.

חוסך זמן

לא צריך להסביר שוב ושוב את אותן המלצות. פשוט שלחו קישור לרשימה המושלמת שלכם.

קל לשיתוף

שתפו את ההמלצות שלכם בלחיצת כפתור - בווטסאפ, אינסטגרם, טוויטר או בכל מקום אחר.

פרטיות מלאה

בחרו האם ההמלצות שלכם יהיו ציבוריות או פרטיות, גלויות רק למי שתבחרו לשתף.

מותאם לנייד

חווית משתמש מושלמת בכל מכשיר - טלפון, טאבלט או מחשב, בכל מקום ובכל זמן.

חינמי לחלוטין

כל הכלים והפונקציות זמינים לגמרי בחינם, ללא הגבלות נסתרות או תשלומים.

שאלות נפוצות

מה זה המלצלי?

המלצלי הוא כלי ליצירת רשימות המלצות יפות וניתנות לשיתוף. זה המקום האידיאלי לשיתוף ההמלצות שלכם על מסעדות, מקומות, שירותים, פעילויות, סרטונים, מתכונים ועוד!

איך זה עובד?

המלצלי ב-3 שלבים פשוטים:

  1. 1. צרו פרופיל והתחילו רשימה חדשה (למשל: "המלצות סקין-קר", "מסעדות מומלצות בתל אביב")
  2. 2. הוסיפו מילות מפתח או הדביקו קישור למשהו שאתם ממליצים עליו. המלצלי יסרוק את הרשת כדי למשוך את כל המידע הרלוונטי.
  3. 3. אשרו או ערכו את המידע כרצונכם, למשל הוסיפו תמונות משלכם או הערה אישית.

זהו! לחצו כדי לקבל קישור לשיתוף הפרופיל או הרשימות שלכם.

איך אני משתף את ההמלצות שלי?

פשוט מאוד! העתיקו את הקישור לרשימת ההמלצות שלכם והדביקו אותו בכל מקום. רוב המשתמשים מוסיפים את הקישור ללינקטרי, לבלוג או לביו שלהם ברשתות חברתיות.

האם אפשר לשתף רשימות באופן פרטי?

בהחלט! הרשימות שלכם יכולות להיות ציבוריות או פרטיות, כך שתוכלו לשתף את ההמלצות שלכם עם כולם, עם הקהילה שלכם, או רק עם אנשים ספציפיים (למשל לקוחות, חברים, משפחה).

כמה עולה השירות?

המלצלי הוא חינמי לחלוטין! המטרה שלנו היא ליצור פלטפורמה נגישה לכולם לשיתוף המלצות איכותיות.

מוכנים להתחיל?

צרו חשבון חינמי והתחילו לשתף את ההמלצות שלכם כבר היום
